### Featured Projects

#### [Crypto-Transaction-Risk-Classification](https://github.com/myishahassan/Crypto-Transaction-Risk-Classification)
Multi-class ML model classifying Bitcoin transactions into risk levels (legitimate, low-risk suspicious, high-risk suspicious, illicit). Demonstrates classification techniques and data analysis.

#### [ECE476 Interactive Article](https://github.com/myishahassan/ECE476InteractiveArticle)
React-based interactive data visualization website built for Housing Rights Initiative. Uses storytelling and data viz to examine housing voucher discrimination in California—**AI for social impact**.

#### [Bayesian Machine Learning](https://github.com/myishahassan/bayesian-machine-learning)
Comprehensive exploration of machine learning from a Bayesian perspective. Jupyter notebooks on probabilistic models and inference.

#### [Drone Control](https://github.com/myishahassan/drone-control)
UAV simulator implementing realistic dynamics with PID and LQR control strategies—**robotics & control systems**.

#### [Quadcopter Control System](https://github.com/myishahassan/quadcopter-control-system)
Autonomous control system for quadcopter drone swarms—**autonomous systems & coordination**.

#### [DSA: Data Structures & Algorithms](https://github.com/myishahassan/dsa1)
Implementations of common data structures and algorithms in C++. Foundation for computational thinking.
